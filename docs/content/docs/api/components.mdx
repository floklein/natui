This entrypoint exports all 37 host components and their prop types without importing the Node process runtime.

```tsx
import { Button, Text, VStack } from '@natui/core/components';
```

Use it for embedded bundles and anywhere that should remain free of Node built-ins. Use the primary `@natui/core` entrypoint for a normal Node-driven application.
